Upload File Batch

Here you can upload a group of files as a single file batch. The files are stored as media files for the organization you choose, and the batch is marked as finished uploading once they have all been stored, which is what triggers any processing the batch type calls for. A Splat batch generates a splat from the batch's video file, using the batch's other files as additional inputs.

The content type of each file is detected from the file if left blank, or used directly. An example would be application/json+frames for specifying the "frames" additional file for splat generation.

You are not a member of any organizations, so you can't upload media files. Add yourself to an organization first.
